#### 自社Webサイト用RAGチャットボット開発【2025/07 - 2025/10】

##### 概要

既存自社サイトのページ右下に配置する質疑応答RAGチャットボットの社内開発。高い学習・実装コストによる属人リスクや工数、他リポジトリへの再現性などを考慮し、RAG機構本体は内製せずにフルマネージドサービスの`Amazon Bedrock KnowledgeBase`を採用。大まかなアーキテクチャは、チャットインターフェースIFからのユーザー入力を、AstroのBE経由でBedrockのAPIに渡し、その返り値を1文字ずつストリーム表示するシンプルなものです。また関連するAWS料金を集計し毎日Slackに通知して、コストを監視できる仕組みも`Lambda`で構築しました。応答情報源となるマークダウンファイルの作成を担当するチームに引き継いで終了。

##### 使用技術

- **フロントエンドFE**： `Astro`, `RadixUI(AssistantUI Primitive)`, `CSS`,
- **バックエンドBE**：`Astro`, `Bedrock KnowledgeBase`, `Bedrock Agents`, `S3`, `S3 Vectors`, `IAM`, `EventBridge`, `Lambda`, `AWS CostExplorerAPI`, `Slack API`
- **インフラ / その他**：`Cloudflare Pages`(Webサイト本体)

#### タスク管理＆通知社内システム開発【2025/05 - 2025/06】

##### 概要

全社的に「今誰が、どんなタスクを持ち、どんな状態にあるのか」の把握を容易にするため、Notionアプリ上でのタスク作成・管理を実現する社内業務システム。タスクのステータス変更およびコメント付与をトリガーとして、2秒以内に関連社員のSlackへ通知します。アーキテクチャとしては、任意のエンドポイントへPOSTリクエストを送信できる`Notion WebhookActions`という機構がクライアント、そのリクエストを元にさらに外部API各種を叩いて情報収集と通知を行う`Hono`製自作APIがバックエンドという構成です。

##### 使用技術

- **フロントエンドFE**：`Notion`, `Notion WebhookActions`, `Slack`
- **バックエンドBE**：`Hono`, `Notion API`, `Slack API`, `Slack BlockKit`
- **インフラ / その他**：`Cloudflare Workers`, `Ngrok`

|開発エンジニア（筆者）|1名|技術選択、アーキテクチャ設計、仕様策定補助、実装、継続保守|先輩開発者がアーキテクチャ設計後、**筆者がそれ以降を引継ぎ**|

  - ドキュメント作成

#### 建築関連会社仲介＆管理サービスWebアプリ開発【2024/08 - 2025/03】

##### 概要

ご依頼主の建築資材商社様の取引先ネットワークを活かした**関連業者および案件仲介Webアプリ**。発注業社（元請）と受注業者（下請）を、案件または会社単位でマッチングさせる2つの仲介機能を主に提供するものです。ユーザー画面にて案件登録・検索・エントリーや、ユーザー検索・マッチ申請などが可能。管理画面にそれら情報を反映させ、先方商社様の営業担当が発注・受注双方に本格的に営業活動して仲介をクロージングする仕様です。そのため**実態はCRMアプリ**と言えます。

##### 使用技術

- **フロントエンドFE**：`React18`, `Next.js14`, `SCSS`, `TailwindCSS`, `Shadcn/ui`, `TanStackQuery`, `TanStackTable`, `Yup`, `ReactHookForm`
  - **バックエンドBE**：`Next.js(ServerActions)`, `Supabase DB/Auth`, `AmazonSES`, `GoogleAppScript`
- **インフラ / その他**：`Cloudflare Workers` ( <- `Cloudflare Pages` <- `Vercel`), `MicroCMS`, `Figma`
