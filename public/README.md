#### 建築関連会社仲介＆管理サービスアプリ開発 （2024/08 - 2025/03)

##### 概要

ご依頼主の建築資材商社様の取引先ネットワークを活かした**業者および案件仲介Webアプリ**。発注業社（元請）と受注業者（下請）を、案件または会社単位でマッチングさせる2つの仲介機能を主に提供するものです。ユーザー画面にて案件登録・検索・エントリーや、ユーザー検索・マッチ申請などが可能。管理画面にそれら情報を反映させ、先方商社の営業担当が発注・受注双方に本格的に営業活動して仲介をクロージングする仕様のため、**実態はCRMアプリ**と言えます。

##### アプリ開発環境の前提

- Web制作案件が主なため、どうしても全社的にアプリ開発における社員のスキルや経験値、人員、工期などの**根本的なリソースが慢性的に不足**。細部まで仕様が検討・ドキュメント化されることは稀なので、 **機能開発者はディレクターとその都度相談し、アプローチや仕様を自ら提案して進めるのが基本**。
- テストコードおよびコードレビューなし。ローカル確認後、各自セルフマージ（当時Git導入からまだ1年未満）
- TS/React + バックエンドも自社で開発するのは会社として初めて
- 同時期に、より規模と優先度が大きい別の受託発案件が開始
- 筆者は入社間もなく専任の開発者として本案件に参加
