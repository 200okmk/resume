現場実務として約1年半、TypseScript言語での小規模なWebアプリ/システムの開発業務に従事しました。**フロントエンドFE, バックエンドBE, インフラ層など実装に必要な全範囲を横断的に、基本単独で担当**してきました（開発職の先輩が在籍中は適宜相談してご協力いただきました）。実装の自走に加えて、UX向上の視点を持ちながら機能仕様やUIも自ら検討・改善提案を重ねました。具体的な主業務は社内ディレクターからの**要求整理、技術選択、各種設計、実装、公開、継続保守、ドキュメンテーションなど**です。またその他並行業務として全社Web制作案件ごとにPaaSインフラ立ち上げとDNS管理、外部API仕様変更や脆弱性リリースへの対応、既存案件の引き継ぎと保守、社内ブログの執筆、エンジニア採用面接なども担当していました。

#### 建築関連会社仲介＆管理サービスWebアプリ開発 （2024/08 - 2025/03)

##### 概要

ご依頼主の建築資材商社様の取引先ネットワークを活かした**関連業者および案件仲介Webアプリ**。発注業社（元請）と受注業者（下請）を、案件または会社単位でマッチングさせる2つの仲介機能を主に提供するものです。ユーザー画面にて案件登録・検索・エントリーや、ユーザー検索・マッチ申請などが可能。管理画面にそれら情報を反映させ、先方商社様の営業担当が発注・受注双方に本格的に営業活動して仲介をクロージングする仕様です。そのため**実態はCRMアプリ**と言えます。

##### 使用技術

- **フロントエンドFE**：`React18`, `Next.js14`, `SCSS`, `TailwindCSS`, `Shadcn/ui`, `TanStackQuery`, `TanStackTable`, `Yup`, `ReactHookForm`
- **バックエンドBE**：`PostgreSQL`, `Supabase DB/Auth`, `AmazonSES`, `GoogleAppScript`
- **インフラ / その他**：`Cloudflare Workers` (<- `Cloudflare Pages` <- `Vercel`), `MicroCMS`, `Figma`

##### 開発環境の前提

- Web制作が主な事業のため、実務未経験の筆者含めてアプリ開発における社員のスキルや経験値、人員、工期などの**根本的なリソースが慢性的に不足している状態**。
- 実装に必要なレベルの仕様まで事前に検討＆ドキュメント化されることは稀なので、**機能開発者はディレクターにその都度ヒアリングし、詳細な仕様とアプローチを自ら提案して進めるのが基本**（具体例は下記セクションにて）
- テストコードおよびコードレビューなし。各自ローカルで確認後、セルフマージする（会社にGit自体が導入されて当時まだ1年ほど）。リリース前に他社員に協力を仰ぎ、ページ毎に総当たりで挙動や文言などを手動確認し修正していく。
- **規模と優先度がより大きい別の開発案件が本案件と同時に開始した**こともあり、最終的に静的ページ以外の大部分を筆者が単独で担当した
- 筆者が参加する以前から、本案件のメイン技術に`TypeScript`, `Next.js`, `Supabase`を採用するという意思決定と、RDBテーブル設計の叩き台作成の2点が既になされていた。
- これら言語とフレームワークを用いた初めてのフルスタックWeb開発受託案件
